# 구조 평가, 빈칸 이력과 후속 Spin Single 점수

이 문서는 [structure.rs](../crates/neyra-core/src/structure.rs)의 보드 특징과 [search.rs](../crates/neyra-core/src/search.rs)의 후보·가방 경계·재개 순위를 계산 순서대로 설명한다. 점수는 탐색에 쓸 순서를 정하는 정책값이다. 물리적인 도달성, 일반 배치의 전 공급 보장, 가방 구축률은 실제 입력과 고정 계획의 P7 검증으로 확인한다. [탐색 재설계 v2](SEARCH_REDESIGN_V2.md)의 모든 기능이 구현되었다는 의미는 아니다.

알고리즘 개선의 고정 기준 소스는 [`af8dac6`](https://github.com/daejunnom/Neyra/commit/af8dac63a9a9155fc28e480246fd617bc855bfb1)이다. 후보는 이 소스에서 출발해 변경점을 분리하며, 전체·가방별 성공률과 화면 자료의 계약은 유지한다. 배포 중인 버전보다 좋아졌다는 사실과 고정 기준 소스에 도달했다는 사실을 구분한다. 고정 기준은 후보보다 불리한 다른 버전으로 바꾸지 않는다. 실제 측정 자료와 실험 도구는 저장소 밖에서 관리하며, 이 문서에는 계산 규칙을 기록한다.

## 1. 어떤 점수를 어디서 쓰는가

| 단계 | 계산하는 값 | 역할 |
| --- | --- | --- |
| 보드 분석 | 구멍, 덮개, 접근성, 작업 공간, 양측 적층과 지붕 | 실제 점유 상태에서 읽은 특징 |
| Terrain | 아래의 `T` | 정적 형상과 구체적 목표에 대한 선호 |
| 미노 접두부 | `Q_prefix` | 비싼 후속 검사 전에 남길 배치 후보 선택 |
| 후속 프로브 | 한 수순의 `F` | 두 가방 안의 실제 입력 수순과 준비·독립성 근거 |
| 가방 경계 | `Q_boundary` | Terrain, 미상환 이력, 후속 근거의 원시 합 |
| 목표 미완성인 첫 가방 | `0.95 Q/(120+|Q|)` | 실제 스핀 가산 없이 기반 품질로 비교 |
| 두 번째 가방 이후의 후보 | `S + 0.95 Q/(120+|Q|)` | 실제 스핀 우위를 제한된 필드 보정과 함께 비교 |
| 경계 재개·대기 계획 | 깊이와 확률을 반영한 `R_P` | 다음 계산 예산을 어디에 쓸지 선택 |
| 공개 최고 중간 경로 | 첫 가방은 원시 Q, 이후는 `S × P / max(7,m)` | 인증된 기반과 후속 진행을 단계별로 비교 |

`S`는 실제 누적 Spin Single 수, `m`은 실제 배치 미노 수, `P`는 설정에 따라 첫 가방을 포함하거나 제외한 인증 접두부의 누적 구축률이다. 예측 스핀은 `S`에 더하지 않는다. 같은 구멍의 비용을 서로 다른 단계에서 계산했다고 해서 그 단계들의 점수를 다시 모두 더하지도 않는다.

## 2. 보드 사실과 작업 공간

### 보드에서 직접 읽는 값

| 특징 | 정의 |
| --- | --- |
| 열 구멍 | 같은 열에서 위에 점유 셀이 있는 빈 셀 |
| 덮인 깊이 | 각 구멍 위의 실제 점유 셀 수의 합 |
| 닫힌 셀·성분 | 네 방향으로 하늘의 빈 공간과 연결되지 않은 빈 셀 및 성분 |
| 묻힌 분절 | 서로 분리된 행의 빈 구간 중 구멍 의무를 포함한 구간의 분리 |
| 열린 표면 분절 | 묻힌 분절로 분류하지 않은 행의 빈 구간 분리 |
| 몸체 여유 | 하늘 쪽에서 2×2 크기의 빈 공간이 이어지는 영역 |
| 접근 부족 | 몸체 여유와 짧은 주변 여유로 설명하지 못한 구멍 또는 조밀한 행의 빈 의무 |
| 방해 질량 | 접근 부족과 연관된 행의 점유 셀 수 |
| 가장 낮은 작업 기준행 | 가장 아래에 남은 미완성 점유행 |

이 마스크들은 SRS+ 입력 경로나 P7를 증명하지 않는다. 특히 네 방향 연결성, 2×2 몸체 여유, 실제 회전 입력은 서로 다른 정보다. 보드 사실을 먼저 보관하고, 점수 계산에서 현재 작업 공간과 그 밖의 저장부를 분류한다.

### 작업 공간과 양측 적층의 가산

낮은 위치에서 몸체 여유가 있고 양쪽에 점유 셀이 있는 폭 2–6의 구간을 살핀다. 이어지는 행에서는 두 셀 이상 겹치며 양측 적층이 있는 모든 연결 가지를 고려해 최대 네 행의 깊이를 계산한다. 처음 만난 왼쪽 가지 하나로 이후 깊이를 결정하지 않으며, 특정 중앙 열을 고정하지 않는다.

기준행보다 `level`행 높은 후보의 낮은 위치 가중치는 다음과 같다.

```text
L(0)=1, L(1)=0.6, L(2)=0.3, L(3 이상)=0
폭 기본값: w=2 → −3.6, w=3 → 4.2, w=4 → 4.8,
           w=5 → 3.2,  w=6 → 2.4
W = L(level) × (폭 기본값 + 0.6 × (연결 깊이−1))
```

선택한 행에서 좌우 공간 각각의 점유 밀도를 구한다. 폭이 3 이상이고 `level<3`일 때:

```text
B = 8 × L(level) × min(왼쪽 점유 셀/왼쪽 열 수,
                       오른쪽 점유 셀/오른쪽 열 수)
```

작업 공간 선택에는 `W+B−0.4×level`을 쓴다. 선택한 뒤 Terrain에는 `W+B`를 넣는다. 마지막의 `−0.4×level`을 Terrain에서 다시 빼지 않는다. 절대 적층 높이를 올리는 것만으로 B가 커지지 않으며 약한 쪽의 밀도가 한계를 정한다.

이 선택은 기존 `af8`의 행 밀도 방식을 사용한다. 기존 낮은 작업행의 B에는 외벽 연결 비율을 별도로 섞지 않으며, 특정 중앙 열이나 모든 표면의 단조 경사를 강제하지 않는다. 아래의 제한된 방향 비용은 현재 입력으로 확인한 포켓 주변에만 적용한다. 작은 표면 굴곡과 옆으로 이동한 작업 공간을 허용한다. 같은 점수의 작업 공간은 보드와 그 반사의 canonical 방향으로 동점을 정한다. 자체 대칭 보드에 동등한 좌우 작업 공간이 있으면 구체적 목표와 대응하는 공간 하나를 Terrain에 사용한다. 이를 두 공간을 동시에 사용하는 근거로 취급하지 않는다. 정적 반사 처리와 유한 예산에서 실제로 발견한 후속 witness의 차이는 구분한다.

### 연결된 작업 공동의 범위

선택한 작업 공간이 기준행보다 두 행 이내에 있을 때, 그 구간의 2×2 여유를 시작점으로 `central_air`를 구한다. 탐색 위쪽은 선택행보다 네 행 이내로 제한하며, 실제 2×2 창이 이어지는 측면으로 연결할 수 있다. 마지막에 지붕 옆의 미노 끝을 위한 좌우 한 칸을 더하되 닫힌 셀은 제외한다. 한 칸짜리 긴 수직 통로를 몸체가 통과했다고 해석하지 않는다.

따라서 `central_air`는 현재 열린 중심 열만 담은 좁은 core와 다르다. 연결된 낮은 측면 공동도 포함할 수 있다. 자체 대칭 보드의 동등한 대안에서는 두 연결 영역의 교집합만 역사 비용을 중립화한다. 서로 분리된 두 작업 공간 중 하나를 선택할 수 있다는 이유로 둘의 이력을 모두 면제하지 않는다. 이 영역의 구멍에 잔여 지형 비용을 남겨 준비 공간으로 취급하고, 같은 셀에 일반 지형·과거 이력·추적 목표의 미계획 구멍 비용을 반복해서 쌓지 않는다. 연결성이 실제 스핀이나 구축률을 보장한다는 의미는 아니다.

## 3. Terrain의 전체 덧셈과 뺄셈

아래 표기는 `BoardFacts`의 원래 집계와 현재 작업 공동을 분리한 집계에 대응한다.

| 기호 | 뜻 |
| --- | --- |
| `H_f`, `C_f`, `B_f`, `S_f` | 연결 작업 공동 밖에서 비용을 받는 구멍·덮개·묻힌 분절·표면 분절 |
| `U_f` | `H_f` 중 즉시 스핀의 요구 빈 셀로 설명하지 않은 구멍; witness가 없으면 `H_f` |
| `H_c` | 연결 작업 공동 안의 구멍 중 즉시 witness의 요구 빈 셀을 제외한 수 |
| `C_c` | 원래 덮인 깊이에서 `C_f`를 뺀 값 |
| `B_c` | 원래 묻힌 분절에서 `B_f`를 뺀 값 |
| `A`, `M` | 접근 부족과 방해 질량 |
| `A_w`, `M_w` | 즉시 witness가 설명하는 접근 부족과 그 클리어 행의 방해 질량 |
| `h`, `n` | 최고 높이와 점유 셀 수 |

집계 차이는 음수가 되지 않게 계산한다. 연결 공동의 잔여 비용은 다음과 같다.

```text
R_connected = 0.5 H_c + 0.05 C_c + 0.5 B_c
```

이는 연결 성분 하나당 고정 0.5점이 아니다. 해당 셀·덮개·분절 수에 비례하는 비용을 Terrain에서 한 번 합산하는 것이다. 같은 공동의 역사적 마스크나 추적 목표에 이 기본 부담을 다시 부과하지 않는다. 현재 즉시 witness는 `H_c`의 자기 footprint를 설명할 수 있지만, 이 식의 덮개·분절 차이까지 자동으로 없애지는 않는다.

전체 결함 subtotal은 다음과 같다.

```text
D = R_connected
  + 2 H_f + 0.5 U_f
  + 0.5 닫힌셀수 + 닫힌성분수
  + 0.25 C_f + 2 B_f
  + 0.06 h² + 0.04 n
  + 3 max(A−A_w,0) + 0.35 max(M−M_w,0)
  + 낮은좁은틈비용 + 직선공동비용
```

즉시 witness가 없으면 `A_w=M_w=0`이다. 공동 밖의 기본 `2 H_f`는 이 버전에서 유지된다. `terrain_score_witnessed`라고 해서 모든 구멍·덮개 비용을 지우는 것은 아니다.

낮은 좁은 틈은 기준행부터 세 행에서만 계산한다. 양쪽이 막힌 폭 1–2의 빈 구간 셀 수를 `N`, 그중 폭 1 구간 셀 수를 `I`라 하면 행마다 `L(level)×(0.8N+1.2I)`를 더한다. 연결 작업 공동, 아래의 얕은 바닥 홈, 즉시 witness의 요구 빈 셀은 제외한다. 가장자리 I 공간은 양쪽이 막힌 내부 틈으로 세지 않는다.

폭 1의 바닥 홈은 별도로 평가한다. 기준행부터 두 행 위까지에서 양쪽이 막힌 한 칸 빈 구간이며, 바로 아래에 바닥 또는 점유 셀이 있고 바로 위에는 실제 두 칸 몸체 여유가 있어야 한다. 이 짧은 홈은 일반 좁은 틈 비용에서 제외하고 `max(0.8×L(level))`의 작은 가점을 받는다. 서로 다른 홈을 합산하지 않는다. 바닥이 없는 긴 한 열 통로와 가장자리 I 공간에는 이 가점을 주지 않는다. 이 분류는 몸체 접근 영역이나 원래 구멍·봉쇄·상환 마스크를 확장하지 않는다. 따라서 단순히 모든 폭 1 구멍의 감점을 없애는 정책은 아니다.

### 일반 요철과 심한 수리 부담

사용할 수 있는 구체적 목표나 동적 작업 공간이 없으면:

```text
T = −D − min(2, 0.0125 일반요철 + 0.0625 S_f) − 수리부담
    − 인접열의존비용 + 바닥홈 + 준비지붕
```

작업 범위가 있으면:

```text
skyline = min(2, 0.02 선형양측단차 + 0.003 제곱양측단차 + 0.0625 S_f)
T = −D − skyline − 수리부담 − 인접열의존비용 − 0.45 지붕옆돌출
    − 0.10 Σ(목표열의불필요한초과높이²) − 즉시포켓방향비용
    + W + B + 바닥홈 + 준비지붕 + 말림지붕가능성
```

일반 표면은 작업 범위 및 그 경계와 분리한다. 목표의 작업 범위는 최종 미노 열과 양쪽 한 열의 여유다. 사용 가능한 목표가 없으면 선택한 동적 작업 공간의 양쪽 한 열까지 사용한다. 작업 범위 보호에 사용할 구체적 목표는 정적 접근 검사를 통과해야 하며, 현재 보드의 정확한 즉시 witness가 있으면 그 근거가 정적 접근 경고에 우선할 수 있다.

큰 단차는 2점의 일반 요철 상한 밖에서 계산한다. `R(e)=min(e,4)²+8max(e−4,0)`라 하자. 서로 붙은 아홉 열 경계 전부에서 높이 차 d를 구하고 다음 의존 비용을 적용한다.

```text
C(d) = 0                         (d=0 또는1)
       0.6                       (d=2)
       0.6 + 3.4 R(d−2)          (d≥3)
e = 높은열높이 − max(낮은열높이, 높은열의실제지붕높이)
인접열의존비용 = Σ [0.25 C(d) + 0.75 C(e)]
```

지붕 설명이 없으면 e=d이므로 2/3/4/5행 차이는 각각 0.6/4/14.2/31.2점이다. 목표나 작업 공간이 해당 열을 선택했다는 이유만으로 이 비용을 면제하지 않는다. 실제 작업 공동의 빈 셀 바로 위에 놓인 점유 셀이 있으면 그 지붕으로 설명되는 부분에 25%를 남기고, 지붕보다 높은 불필요한 탑은 전부 부담한다. 줄 삭제 뒤 떠 있는 지붕도 아래쪽에 현재 작업 공간이 있으면 설명할 수 있으며, 빈 하늘의 고립 블록은 설명하지 못한다. 점수 합산은 반사되는 열 경계를 쌍으로 묶어 미세한 부동소수점 오차가 준비 검사 분기를 좌우하지 않게 한다.

내부 한 열 골짜기와 지붕 밖의 별도 돌출은 추가 수리 부담으로 남긴다:

| 수리 항목 | 초과량 e | 비용 |
| --- | --- | ---: |
| 내부 한 열 골짜기 | 양옆 중 낮은 높이와의 깊이 차이에서 2를 뺀 양수 부분 | `0.60 R(e)` |
| 목표 지붕 옆의 고립된 돌출 | 허용 지붕·바깥 적층을 모두 넘는 높이에서 3을 뺀 양수 부분 | `0.45 R(e)` |

이 버전은 연결 공동의 바로 위 점유 셀에서 얻은 `cavity_roof_tops`를 기존 방식대로 보존한다. 같은 열의 허용 지붕 높이를 양측 단차·돌출 계산에서도 사용한다. 이 허용값은 모든 경우에 즉시 witness 하나의 지붕으로만 제한된 값이 아니다. 해당 지붕보다 더 높은 불필요한 탑은 계속 감점하며, 이 정적 허용으로 입력이나 P7 성공을 인증하지 않는다.

### 위로 말리는 공동과 긴 직선 벽

선택한 낮은 작업 공간에서 최대 다섯 점유행을 따라 폭 2–6의 실제 내부 빈 구간을 살핀다. 양쪽 경계가 점유되어 있고, 인접 행 사이에 두 칸 이상의 몸체 여유가 이어져야 한다. 서로 다른 연결 가지는 별도 경로로 유지한다. 가장자리의 열린 공간이나 한 칸짜리 I 통로를 이 넓은 공동으로 분류하지 않는다.

아래쪽 구간의 폭이 3 이상이고 위쪽이 좁아질 때, 이전 옆벽부터 안쪽으로 연속해 붙은 점유 셀을 지붕으로 발전할 수 있는 말림으로 센다. 공중에 떨어진 블록, 완전히 닫힌 뚜껑, 빈 하늘은 가점 대상이 아니다. 한 경로에서 중복을 제거한 말림 열 수를 c라 하면:

```text
말림지붕가능성 = L(level) × max_연결경로 min(6, 1.5c)
L(0)=1, L(1)=0.6, L(2)=0.3
```

이 항은 특정 마무리 미노가 아직 정해지지 않아도 받을 수 있는 최대 6점의 형상 가점이다. 아래의 구체적인 목표를 위한 준비 지붕 최대 18점과 구분한다. 전체 필드 점수가 음수여도 이 양의 항을 줄이지 않는다. 절대 높이를 더 쌓거나 다른 경로들의 말림을 합쳐 점수를 늘리지 않는다. TeaL의 두 번째 가방 잔여 공동은 이 형태를 설명하는 참고 예이며, 알려진 수순이나 그 성공률을 Neyra에 주입하는 근거가 아니다.

같은 위치와 같은 폭의 빈 구간이 연속해 유지되는 직선 구간의 행 수를 r이라 한다. 세 행부터 비용을 부과하고, 구간의 폭이나 위치가 바뀌면 연속 길이를 새로 센다.

```text
직선공동비용 = max_연결구간 min(8, 3 × max(r−2−e, 0))
e = 그 구간의 클리어 footprint를 설명하는 정확한 즉시 스핀이 있으면1,
    그렇지 않으면0
```

즉시 근거가 없으면 3/4/5행의 비용은 각각 3/6/8점이다. 길이를 제한한 동일 구간에서 최대 한 창만 즉시 witness로 설명할 수 있다. 다른 공동의 스핀이나 준비 뒤에야 가능한 스핀은 그 비용을 없애지 않는다. 여러 대안의 비용은 합산하지 않고 가장 큰 구간 비용 하나를 사용한다. 위쪽의 말림만으로 아래 직선 구간의 비용을 추가 면제하지 않으므로, 한 공동이 큰 지붕 가점과 긴 직선 부분의 비용을 함께 받을 수 있다.

두 항은 `ΔT=말림지붕가능성−직선공동비용`으로 합쳐진다. 구멍·접근 부족·이력 마스크·상환·실제 스핀 수·공급 성공률은 바꾸지 않는다. 첫 가방 접두부에서는 아래의 구조 배율을 받고, 경계에서는 기존 `2T`에 포함된다. 상수는 정책값이며 형태 자체로 회전 입력이나 완주를 증명하지 않는다.

### 준비 지붕의 양의 점수

준비 지붕은 구체적 `SingleGoal`에 연결된다. 선택한 작업 공간과 클리어 행이 기준행보다 두 행 이내에 있고, 최종 미노의 네 셀이 비어 있으며, 그 셀 바로 위에 기존 블록이 하나 이상 있어야 한다. 미노 열이 작업 공간과 겹치고, 목표 행에 필요한 점유 셀의 절반 이상이 이미 놓여 있어야 한다.

```text
준비율 = 현재채운목표행의무 / 필요한목표행의무
행가중치 = 기준행이면1, 한행위면0.75, 두행위면0.5
준비지붕 = min(18, 3 × (2 + 1.5 min(지붕접촉수,2) + 0.1875 B))
           × 준비율 × 행가중치
```

기존 지붕은 스핀 실행 전에도 이 값을 받는다. 이 항은 전체 필드의 손상 정도나 총점의 부호에 따라 축소하지 않으며, 목표 접근 경고로 작업 범위 보호가 열리지 않았더라도 위 형상 조건을 만족하면 독립적으로 더한다. 구멍·접근·높이·누적 이력의 음의 항은 그대로 계산하므로 지붕 가점이 높아졌다는 사실만으로 필드 전체가 양수가 되는 것은 아니다. `W`, `B`, 준비 지붕을 즉시 witness가 없다는 이유만으로 다시 줄이지 않는다. 다만 이 세 항은 준비 선호이며 실제 스핀 수, 공급 성공률, 과거 셀의 상환으로 바꾸지 않는다. 오래된 잔여 지형보다 높은 곳에서 현재 바로 실행한 목표만 아래의 활성 지붕 보정을 사용할 수 있다. 그 경우에도 아래 셀이나 이력을 초기화하지 않는다.

### 즉시 입력이 확인된 포켓의 방향과 높은 활성 지붕

현재 보드에서 일반 준비 없이 실행된 `immediate_anchor`가 있을 때만 방향 비용을 적용한다. 그 목표와 겹치고 클리어 행이 두 행 이내인 선택 작업 공간이 있으면 그 공간을 기준으로 삼고, 그렇지 않으면 실제 목표의 열 범위를 사용한다. 빈 첫 준비 단계나 아직 실행하지 않은 목표에는 이 추가 비용을 넣지 않는다.

목표 왼쪽에서는 바깥쪽 열보다 안쪽 열이 높은 양, 오른쪽에서는 바깥쪽 열보다 안쪽 열이 높은 양을 각 rᵢ라 한다. 음수는0이다.

```text
선형안쪽상승 = Σ rᵢ
심한안쪽상승 = Σ min(max(rᵢ−1,0),4)²
즉시포켓방향비용 = min(4, 0.15×선형안쪽상승 + 0.10×심한안쪽상승)
```

한 칸의 보통 굴곡에는 작은 선형 비용만 남고, 큰 안쪽 기둥에는 별도 제곱 부분이 생긴다. 바깥 높이를 계속 쌓는 데 보너스를 주지 않으며, 최고 높이·추가 질량·기존 수리 부담도 유지한다. 이4점 상한은 Terrain 단위이므로 경계의 `2T`에서는 최대8점이다.

즉시 목표의 클리어 행이 기존 가장 낮은 기준행보다 세 행 이상 높으면, 낮은 지붕 보상 대신 목표 자체의 활성 행을 기준으로 지붕을 계산한다. 최종 미노 셀이 비어 있고 바로 위의 실제 지붕 접촉이 있으며, 목표 행 의무의 절반 이상이 채워졌는지 확인한다. 해당 행의 목표 열 좌우에서 점유 셀 수와 외벽부터 연속한 점유 셀 수를 함께 사용한다. 각 측면의 밀도는 `(점유셀수+외벽연속셀수)/(2×측면열수)`이며, B_active는 양쪽 중 작은 밀도에8을 곱한 값이다. 목표가 필드 가장자리에 닿아 한 측면이 없으면 B_active는0이다. 이는 높은 활성 지붕의 보조 항이며, 기존 낮은 작업행의 B를 바꾸지 않는다.

```text
활성지붕 = min(18, 3 × (2+1.5min(지붕접촉수,2)+0.1875B_active))
           × 목표행준비율 × 목표최하단셀에대한행가중치
```

행가중치는 클리어 행이 목표 최하단과 같으면1, 한 행 위면0.75, 그보다 높으면0.5다. 기존 낮은 목표는 원래 준비 지붕 공식을 그대로 사용한다. 높은 하늘이나 미실행 목표만으로 이 추가 가산을 열지 않으며, 새 작업행 아래의 점유·빈칸 이력·기존 확률 자원은 유지한다. 이 가산은 기존 `cavity_roof_tops` 처리 전체를 대체하지 않는다.

## 4. 빈칸 이력과 실제 상환

`debt`에는 일반 배치가 새로 만든 구멍의 셀 이력을 보관한다. 다음 상태를 만들 때 줄 삭제 좌표에 맞춰 이력을 압축한 뒤 실제로 채운 셀을 제거한다. 일반 배치에서 새로 생긴 구멍을 추가한다. 지붕만 열어 열 구멍이 아니게 되어도 아직 빈 해당 셀은 원래 이력에 남는다.

현재 비용 대상은 `penalized_debt(debt) = debt ∖ central_air`이다. 작업 공동으로 분류된 이력을 일시적으로 낮은 지형 부담으로 다루지만, 원래 마스크를 삭제하지 않는다. 작업 공간이나 접근 분류가 바뀌면 같은 셀에 역사적 비용이 다시 적용될 수 있다. 열린 지붕을 셀 상환으로 기록하지 않는다.

후속 프로브의 `paid`는 프로브 시작 시 비용을 받던 셀만 별도 장부에 넣고, 하나의 일관된 첫 예측 가방 수순이 실제로 채우거나 행과 함께 지운 수를 센다. 처음부터 역사적 비용이 없던 연결 작업 공동을 나중에 채워도 추가 상환 점수를 받지 않는다. 서로 다른 예측 대안의 상환을 더하지 않는다.

## 5. 미노 접두부: 좋은 준비 후보를 남기는 점수

후속 프로브 전에 후보가 제거될 수 있으므로 정적 준비 선호는 미노별 순위에서도 사용한다. 구체적 추적 목표를 G, 현재 비용 대상 이력 수를 d라고 하면:

```text
V = 2 T(G, 정확한witness아님) − 4d + 일반배치의지붕·의존보정
    − 8 × G의남은의무 − 4 × G밖의미계획구멍
```

마지막 두 항은 추적 목표가 있을 때만 적용한다. 미계획 구멍은 연결 공동 및 G의 요구 빈 셀 밖에 있는 구멍이다. 목표는 한 줄 클리어를 노리는 최종 미노 모양, 반드시 채울 셀, 반드시 비울 셀과 지지 조건으로 구성한다. 실제 스핀 도달성 검사를 통과하지 않은 목표를 witness로 취급하지 않는다. 본 생성기는 `preserved_after`로 목표의 빈 셀과 정확히 한 줄을 남기는 조건을 확인하고, 이를 잃으면 추적 목표를 해제한다. 첫 가방은 모든 라운드에서 다음 가방의 마무리 미노를 고려할 수 있으므로 현재 가방에서 그 종류를 이미 사용해도 목표를 유지할 수 있다. 두 번째 가방 이후에는 마무리 미노를 다른 곳에 소비하면 목표를 해제한다. 실제 줄 삭제 뒤에도 기존 목표를 해제한다.

작은 미실행 준비 보너스와 후속 프로브의 목표 지지 배치는 모두 `preserved_after`의 조건을 유지해야 한다. 목표 빈칸을 채우지 않고, 마무리 미노를 넣을 때 목표 클리어 행 외의 행까지 완성되는 준비를 제외한다. `accepts_support`는 footprint의 빈칸과 유용한 지지를 확인하고, 간접 받침은 별도의 제한된 가지로 다룬다. 실제 일반 배치를 적용한 결과가 0줄인지 확인한 뒤에도 목표 보존을 검사한다. 마무리는 실제 입력을 재생해 정확히 1줄을 지운 스핀인지 확인한다. 일반 지지 배치만으로 Single 준비나 공급 성공을 인증하지 않는다.

### 출발점의 독립적인 바닥 배치

첫 가방의 모든 접두부는 기반을 만드는 단계다. 준비 전용 라운드뿐 아니라 스핀을 허용한 라운드와 이미 우연한 스핀이 발생한 접두부에도 같은 품질식을 적용한다. 작업 공간·양측 적층·후속 준비를 남기면서, 초반에는 독립적인 착지 여지를 보존한다. 현재 가방에 놓은 미노 수를 n, 준비 제안의 점수를 U라 하면:

```text
Q_prefix = 0.35U + w(n)V                 (첫 가방의 모든 접두부)
Q_prefix = V + 0.25U                     (두 번째 가방 이후)
w(n) = 0.06 + 0.06 × min(max(n−3,0),4)
배치 수 n:  1     2     3     4     5     6     7
w(n):      0.06  0.06  0.06  0.12  0.18  0.24  0.30
```

실제 세션은 모든 root 생성에서 `relaxed_setup=true`를 설정하므로 U의 계수 k는 0.35다. 앞의 세 미노에서는 바닥 선택의 자유를 보존하고, 마지막 네 미노에서는 완성될 작업 공간과 지붕이 접두부 선택에 더 큰 영향을 준다. 첫 가방의 실제 스핀은 프레임과 인증서에 계속 기록하며, 목표 완성이나 물량·비용 하한에도 사용한다. 이 정책은 첫 가방 스핀을 금지하는 규칙이 아니다.

`setup_score`의 전체 비용은 다음과 같다.

```text
U = −18 × 독립지지가없는목표수
    −5 × (이미쓴기초접촉셀수 + 남은미노의기초예약량)
    −9 × max(선행의존성이있는미노수−1,0)
    −1 × 의존간선수
    −12 × 양방향의존미노쌍수
```

독립 지지는 가방 시작 보드에 해당 목표를 기하학적으로 놓을 수 있는지로 검사한다. 같은 열의 위아래 목표 셀로 단순 선행 관계를 만들며, 실제 회전·OR 지지·홀드의 모든 선택을 증명하는 검사는 아니다. 남은 기초 예약량은 O에 두 셀, 다른 미노에 한 셀씩이다. 바닥을 넓게 먼저 사용해 남은 미노를 모두 특정 순서에 의존하게 만드는 준비를 줄이기 위한 정렬값이다.

같은 `Q_prefix`에 모든 라운드에서 0–2 범위의 순서용 jitter를 더한 뒤 7절의 후보 순위식에 넣는다. 이 값은 필드 근거나 인증서가 아니다. 완료 가방은 최대 12개를 후속 검사 대상으로 남기고, 정제 뒤에는 최대 8개를 보존한다. 첫 가방에는 다른 경로의 스핀 수, 같은 깊이의 스핀 격차, 스핀 우선 bucket 지름길을 적용하지 않는다. 필요한 물량·비용과 공급 상한 검사는 유지하며, 제한된 beam에서 탈락했다는 사실은 구축 불가능성의 증명이 아니다.

일곱 목표가 모두 정해졌고 스핀 목표는 아직 끝내지 못한 0클리어 가방에는 별도의 필요한 조건 검사가 있다. 시작 필드와 목표의 논리적 합집합이 일곱 종류를 중복 없이 포함하고 완성 행이 없음을 확인한 경우에만, 서로 다른 모든 첫째·둘째 공급 조합을 검사한다. 첫 미노의 spawn과 무클리어 기하 배치, 그 결과 보드에서 둘째 미노의 spawn과 무클리어 기하 배치가 가능해야 한다. 첫 가방의 허용 반사를 사용할 때에는 두 배치가 하나의 방향에서 함께 가능해야 하며, 각 배치의 방향을 따로 골라 합치지 않는다. 이 조건을 통과하지 못한 후보는 비싼 후속 정제 전에 제외한다. 불명확한 합집합, 실제 클리어가 있는 가방, 목표를 이미 완성한 접두부는 이 검사를 우회한다. 통과는 실제 입력 도달성이나 P7 성공의 증명이 아니다.

### 일반 배치의 지붕 형성과 남은 미노 의존성

모든 종류의 무클리어 배치에 대해 새 지붕으로 사용되는 셀과 일반적인 높은 단차를 구분한다. 이번 미노가 실제로 기존 작업 공동 위에 새로 놓은 지붕 열 수를 c라 하면 즉시 형성 가점은 `min(18,6c)`다. 이 가점은 남은 재고가 없어도 실제 배치된 지붕에 주며, 정적 Terrain의 지붕 선호와 별도의 접두부 순서값이다.

배치 전후의 인접열 의존 비용 증가를 Δ라 한다. Δ가 4점보다 작으면 추가 준비 검사를 하지 않는다. 그 이상이면 남은 미노 중 하나를 바뀐 열 근처에 기하학적으로 내려놓는 경우를 비교한다. 각 종류의 서로 다른 회전과 가로 위치를 살피되 재귀 탐색이나 새 전체 보드 분석은 하지 않는다. 목표 빈 셀을 침범하거나 한 줄이라도 지우는 후보, 현재 작업 공동과 관계없는 빈칸을 새로 덮는 후보는 제외한다. 의도한 마무리 미노를 이 수리 재고로 다시 사용하지 않는다.

후속 배치가 새 지붕으로 덮는 열 수를 c_f, 그 배치로 줄일 수 있는 비용을 r이라 하면:

```text
0 ≤ r ≤ Δ
후속지붕가치 = min(12, 3c_f + 0.5r)       (실제 작업 공동 위 지붕 생성)
일반수리가치 = min(6, 0.25r)               (새 지붕 없이 단차를 완화)
일반배치보정 = min(18,6c) + 최고후속가치 − 0.25Δ   (Δ≥4)
               min(18,6c)                          (Δ<4)
```

한 미노·한 배치의 최고값만 사용하며 서로 다른 종류나 위치의 이익을 합산하지 않는다. 지붕을 만들 수 있는 경우에도 특정 미노가 필요하다는 부담을 남긴다. 이 비교는 낙관적인 기하 준비 가능성이며 실제 입력 도달성이나 공급 순서의 인증은 아니다. 실제 스핀과 구축률은 기존 실행·공급 검증으로만 결정한다. 이 일반식이 이전의 내부 세로 I 전용 수리 보정을 대체한다.

### 같은 구멍의 부담 예시

다음은 다른 형상·접근 비용을 제외한 산술 예시다. 측정 결과가 아니다.

| 즉시 witness가 없는 셀 | 미노 접두부의 원시 부담 | 가방 경계의 원시 부담 |
| --- | --- | --- |
| 연결 작업 공동의 구멍 | 잔여 구멍 비용 `2×0.5=1`; 덮개·분절 잔여 비용은 별도 | 같은 Terrain 배율로1; 역사적12를 추가하지 않음 |
| 공동 밖 구멍, 역사 이력 있음 | `2×(2+0.5)+4=9` | 미상환이면 `2×(2+0.5)+12=17` |
| 위 셀이 추적 목표 밖에도 있음 | 준비 경로의 미계획 비용4를 더해13 | 접두부의 추적 목표 비용을 경계에 다시 더하지 않음 |

첫 가방에서는 이 V 전체에 배치 수에 따른 w(n), 즉 0.06–0.30이 적용된다. 따라서 표의 원시 비용과 최종 `Q_prefix`의 영향은 다르다. 연결 공동의 감점을 남기는 것과 공동 밖의 모든 중복 비용을 없애는 것은 다른 정책이며, 현재 식은 후자를 수행하지 않는다.

## 6. 두 가방의 실제 입력 수순과 준비·독립성

후속 프로브는 첫 재고에서 최대 일곱 미노를 실제로 배치한다. 첫 예측 가방에서 두 스핀 이상을 얻고 일곱 종류를 모두 썼을 때만 두 번째 재고를 연다. 가방을 넘을 때 시작 필드·논리 삭제행·공급 상한용 마스크를 갱신한다. 목표는 하나의 일관된 경로에서 최대 여섯 Spin Single이다.

첫 스핀을 얻기 전에는 마무리까지 최대 네 배치를 살피고, 스핀 사이의 지지 준비는 최대 세 일반 배치까지 전개한다. 현재 추적 목표뿐 아니라 남은 마무리 미노의 종류와 위치가 다른 목표도 다시 찾는다. 목표 지지 배치는 마무리 미노를 소비하지 않고 실제 0줄 배치와 목표 보존 조건을 만족해야 한다.

구체적 목표가 아직 없고 프로브 시작 또는 직전 스핀 뒤 일반 준비를 하지 않은 구간에는, 목표를 정하기 전에 공동을 바꾸는 일반 미노 한 개도 시도한다. 남은 재고가 두 종류 이상이어야 하며 뒤의 마무리 배치 공간을 남겨야 한다. 이 가지는 실제 도달 가능한 무클리어 삽입을 사용하고, 정적 점수가 높은 최대 두 결과 안에 현재 작업 열의 기존 높이 아래로 들어가는 결과 하나를 남길 수 있다. 준비 후에는 바뀐 보드와 남은 재고로 목표를 다시 찾는다. 목표를 정하지 않은 준비 한 번도 일반 준비 수에 포함한다.

첫 예측 가방이 두 스핀 이상을 얻으면 남은 일반 미노를 정리해 재고를 소진하는 가지를 별도로 둔다. 이 가방 마무리용 정리는 세 번의 지지 준비 제한과 구분한다. 실제 실행 없이 다음 가방의 미노를 빌려오지 않는다. 첫 예측 가방의 스핀·상환·방해 질량은 그 가방의 값으로 고정하며, 두 번째 가방의 결과와 합쳐 필요조건을 낙관하지 않는다.

프로브의 처음과 각 스핀 직후에는 마무리 미노 종류와 점유 위치를 섞어 작업을 예약한다. 같은 위치의 여러 회전·지지 조건이 다른 위치를 모두 밀어내지 않게 순서를 나누되, 입력 질의 전에 그 회전 대안을 하나로 합치지 않는다. 일반 작업 큐는 최대 192개, 예약 큐는 최대 24개다. 기본 작업량은 프로필에 따라 64 또는 96이며, 실제 후속 진행이 있을 때 늘어나 최대 320 또는 352가 된다. 따라서 대안을 보존하는 정책도 유한 예산 안의 선택이며 모든 후속 수순을 열거했다는 뜻은 아니다.

### 한 수순의 기본 평가

첫 예측 가방의 스핀 수를 g₁, 두 번째의 추가 스핀을 g₂, 첫 가방의 일반 배치 수를 q, 처음 유료였던 셀의 상환 수를 p라고 한다. T₀와 T₁은 각각 프로브 시작과 첫 예측 가방 말의 `facts.score()`다.

```text
A₁ = −10q + 6p + 0.25(T₁−T₀)
F_line = 60g₁ + 18g₂ + A₁
대표수순순위 = g₁ + 0.3g₂ + 0.45A₁/(120+|A₁|)
```

첫 예측 가방이 아직 끝나지 않았다면 그 실제 접두부의 값을 쓴다. 같은 배정의 접두·연장은 하나의 수순으로 관리하며, 최대 여섯 수순, 즉 대표 하나와 대안 다섯 개를 보존한다. 가장 높은 대표수순순위의 경로를 먼저 남긴 뒤, 다른 첫 마무리 미노 종류와 다른 점유 위치의 수순을 우선 보존하고 가까운 변형으로 나머지를 채운다. 각 수순은 자기 재고와 배치 이력을 가지며, 다른 타일링의 스핀이나 상환을 합산하지 않는다.

가까운 스핀과 먼 스핀의 가중치는 다르다. 총예측이 하나 더 많다는 이유만으로 모든 지형 차이보다 우선하도록 만드는 규칙은 없다. 실제 P7 검증된 진행과 한 기하학적 프로브의 수순을 분리한다.

### 준비와 배치 순서의 독립성

| 항목 | 계산 | 상한 |
| --- | --- | ---: |
| 실행한 첫 스핀의 준비 정도 | `15/(1+q)`; 선행 스핀 없음, 일반 준비 q≤2 | 15 |
| 아직 마무리하지 않은 구체적 준비 | `5/((1+r)×(1+q))`; 남은 의무 r≤4, 목표 보존 및 마무리 재고 필요 | 5 |
| 두 수순의 순서 독립성 | `20/(1+q_A+q_B)`; A→B와 B→A 모두 실행해 같은 필드 도달 | 20 |

준비 정도는 앞의 두 근거와 여러 목표 중 **가장 큰 값 하나**만 쓴다. 바로 실행한 첫 스핀은15, 일반 준비 한 개 뒤에는7.5, 두 개 뒤에는5다. 일반 준비 세 개 뒤의 스핀도 한 수순의 실제 후속 스핀으로 기록할 수 있지만, 이 실행 준비 보상과 독립성 검사에 보관하는 첫 스핀 수순은 q≤2로 제한한다. 다른 포즈의 수나 같은 마무리 미노의 여러 슬롯을 더하지 않는다.

독립성은 준비까지 포함한 미노 재고와 논리 셀이 충돌하지 않는 수순을 대상으로 한다. 최대 여섯 개의 첫 마무리 수순을 보관하며, 같은 종류의 마무리 미노라도 최종 점유 위치가 다르면 별도 대안으로 남길 수 있다. 같은 종류를 쓰는 두 대안을 동시에 실행한 것으로 세지 않는다. 쌍의 중복은 미노 종류만으로 판단하지 않고 구체적 배정·회전·마무리 역할을 사용하며, 최대 세 쌍만 검사한다. 각 순서에서 일반 배치는 0줄, 마지막 배치는 정확히 1줄을 지운 스핀이어야 하고 A→B와 B→A가 같은 종료 필드에 도달해야 한다. 가장 좋은 한 쌍만 쓴다. 최대 18회의 추가 종점 질의도 기존 프로브 예산 안에서 수행한다. 다른 방향이나 미검사 쌍은 미확인으로 남는다.

전체 프로브 값은 다음과 같다.

```text
F = F_line + 최선준비값 + 최선독립성값
```

준비·독립성의 합은 최대35다. 준비 지붕의 정적18점과 이 입력 근거들은 역할이 다르지만 동일한 원시 Q 안에서 경쟁한다. 어느 값도 실제 스핀 수 또는 P7 성공률에 더하지 않는다.

현재 보드에서 일반 준비 없이 바로 실행한 첫 스핀만 `immediate_anchor`가 된다. 준비 뒤의 첫 스핀은 `anchor`로 수순을 구분하고 준비 보상을 받을 수 있지만, 아직 준비하지 않은 원래 보드의 즉시 witness가 되지는 않는다.

## 7. 가방 경계와 실제 스핀 순위

후속 검사를 마친 경계에서 현재 비용 대상 이력 수를 d, 첫 예측 가방의 상환 수를 p라 하면:

```text
Q_boundary = 2T(immediate_anchor) + F − 12max(d−p,0)
```

지형, 미해결 셀, 예측 스핀, 준비, 독립성을 원시 단위로 직접 더한다. 추가적인 `48R/(120+|R|)` 압축이나 `120×총예측수` 우선항을 넣지 않는다. `F_line`의 `6p`와 미상환 역사 비용의 감소는 별도 항이다. 처음 유료였던 셀이 하나 실제로 상환되면 이 두 항에서 합계18의 변화가 생길 수 있다. 처음부터 연결 공동으로 분류한 무이력비용 셀에는 이 상환 가산을 부여하지 않는다.

후보를 선택하는 마지막 순위는 첫 가방의 기반 단계와 실제 목표 완성을 구분한다.

```text
q(Q) = 0.95Q/(120+|Q|)
rank(S,Q) = q(Q)                         (목표 미완성인 첫 가방)
rank(S,Q) = S + q(Q) + 1                 (첫 가방에서 실제 목표 완성)
rank(S,Q) = S + q(Q)                     (두 번째 가방 이후)
```

목표 미완성인 첫 가방은 실제 S를 순위에 더하지 않는다. 기반을 만드는 중에 얻은 스핀도 기록은 유지하지만 더 좋은 작업 공간과 후속 근거를 자동으로 앞서지 않는다. 실제 목표를 끝낸 첫 가방은 별도 우선 단계를 사용해, 작은 목표의 완성도 미완성 기반에 밀리지 않게 한다. 목표 완성 배치에는 별도의 후보 용량을 두고 대기 계획에서도 terminal을 먼저 선택한다.

두 번째 가방 이후의 보정은 −0.95와 +0.95 사이이므로 같은 깊이와 확률 자원에서 실제 2스핀 차이는 뒤집히지 않는다. 실제 1스핀 차이는 필드 품질과 경쟁할 수 있다. Q에 실제 S를 다시 넣거나 이 정규화 뒤에 무제한 형상 보너스를 더하지 않는다. 화면의 `fieldQuality`는 정규화 전의 Q이며, 첫 가방의 대표 표시값도 이 원시 품질이다.

## 8. 깊이·확률을 고려한 재개 순위

생산적인 배치 수 `L=max(7,m−7)`, `a=7/L`을 사용한다. 준비 가방을 제외하는 이 보정은 내부 재개에만 쓴다. 첫 가방에서 사용하는 스핀 항 `S_schedule`은 0이며, m>7부터 실제 누적 S를 사용한다.

```text
R = S_schedule×7/L + 0.2Q_use/(120+|Q_use|)×a
shift = 0.2a
R_P = (R+shift)×P − shift
```

P가 1이면 확률 곱셈을 거치지 않고 R의 계산식을 그대로 반환한다. 품질과 shift를 같은 a로 조정하므로 가방이 깊어질수록 품질의 영향만 커지지 않는다. 품질이 음수인 0스핀 상태에서도 확률을 줄여 순위를 올릴 수 없다. 첫 가방의 스핀 항을 0으로 만드는 것은 스케줄러의 선택이며, 인증된 실제 스핀을 지우지 않는다.

일반 재개에서는 Q를 다음과 같이 일시 보정한다. t는 마지막 검증 자식 개선 뒤의 시도 수, age는 마지막 배정 이후의 거리로 최대128, b는 완주 총비용의 낙관적 하한이다.

```text
speculative = max(F,0) + 12p
Q_schedule = Q_boundary − speculative×t/(t+4)
             +1.2age −6t −32log₂(총시도수+1)
             −2max(b−현재예산,0) −0.8max(b−선호미노제한,0)
Q_use = Q_schedule + ΔQ_probability
```

이 값만 재개 순위에 넣는다. 실제 인증 스핀·확률·저장된 `fieldQuality`를 바꾸지 않는다. 대기 계획은 그 계획의 원시 Q에 부모의 확률 페이스 보정만 더하고, 확률 가중치에도 부모의 검증된 P만 쓴다.

### 종료 시점까지의 확률 소비 페이스

전체 성공률 하한이 100% 미만일 때에는 인증된 확률 자원을 종료 시점까지 일정한 로그 속도로 쓴다는 가정과 비교한다. 전체 하한을 f, 목표 스핀 수를 G, 고정된 미노 기준을 H라고 한다. N은 H까지 전체 성공률에 포함할 가방 수이고, n은 그중 이미 인증된 가방 수다.

```text
H = max(1, min(탐색상한, max(미노제한, ceil(10G/4))))
N = ceil(H/7) − (첫가방확률제외이면1, 아니면0)
paced = min(n/N, 1)
spent = max(ln(P)/ln(f), 0)
ΔQ_probability = 24 × clamp(paced−spent, −1, 1)
같은 페이스의 접두부 확률 = f^paced
```

같은 시점에 확률이 `f^paced`보다 많이 남아 있으면 양의 보정, 적게 남아 있으면 음의 보정을 받는다. 보정 범위는 원시 스케줄링 Q의 −24에서 +24까지이며, 그 뒤에 위의 제한된 품질식과 확률 가중치를 적용한다. 전체 성공률 100%, N=0, 확률이 0인 경우에는 이 보정을 끈다. 아직 검증하지 않은 대기 가방은 부모의 P와 n만 사용하므로 자기 가방이 완료된 것처럼 시간 경과 보상을 받지 않는다.

H는 설정된 미노 제한과 물량 하한에서 정하며 탐색 중 `active_budget`을 넓혀도 바꾸지 않는다. 따라서 이미 사용한 확률 예산이 탐색 상한 확장으로 복구되지 않는다. 내보내기의 `projectedFinalProbability`는 보정이 켜져 있고 n>0일 때 `P^(max(N,n)/n)`으로 계산한 같은 페이스의 설명값이다. 그 밖에는 null이며, 예정 가방 수를 넘기면 현재 P를 그대로 유지한다. 이 값은 후속 가방의 예측 인증서가 아니며, 채택 하한·실제 확률·저장된 Terrain·공개 효율에는 더하지 않는다.

### 깊은 인증 경계의 탐색 기회

기본 탐험은 8번의 배정 간격으로 기회를 만들고 네 단계를 순환한다. root의 대기 계획 또는 새 생성, 미시도 첫 가방 기반, 두 가방 이상인 깊은 인증 경계, 오래 기다린 적격 노드가 차례로 기회를 얻는다. 특정 단계에 후보가 없으면 기존의 오래 기다린 적격 노드 선택으로 돌아간다. 별도의 긴 구간 프로브가 먼저 선택될 수도 있으므로 전체 계산량의 4분의 1을 깊은 경로에 고정 배정한다는 뜻은 아니다.

깊은 단계는 기존 비용·스핀 페이스·품질 조건을 통과한 노드 중 깊이를 우선하고, 같은 깊이에서는 기다린 시간과 재개 순위를 본다. 개선 없이 네 번 이상 시도한 노드는 최소 32번의 배정 간격을 기다려야 이 예약 기회를 다시 받을 수 있다. 이미 대기 계획이 있으면 먼저 검증하고, 없으면 추가 생성 한 번을 허용한다. 실패한 반복만으로 일반 탐색 폭을 넓히지 않는다.

트리 용량을 다 썼을 때에도 미시도 첫 가방 2–8개와 적격 미시도 깊은 노드 2–4개를 일반 교체 대상에서 우선 제외한다. 개수는 beam 폭으로 정하며, 다른 교체 대상이 없으면 이 예약도 해제될 수 있다. 교체는 부모·focus·대기 검증에 참조되지 않는 말단에서만 수행하고, 완성된 인증 기록은 별도로 보관한다. 이 예약은 계산 기회를 남기는 정책이며 새로운 필드 점수나 완료 보장이 아니다.

## 9. 화면의 최선과 확률 검증

공개 중간 기록은 인증된 첫 가방 기반과 두 가방 이상 진행한 경로를 구분한다. 두 가방 이상인 인증 경로가 있으면 첫 가방 기반보다 우선 표시한다. 같은 단계에서는 다음 순서로 비교한다.

| 비교 단계 | 우선순위 | 화면의 대표값 |
| --- | --- | --- |
| 두 기록 모두 첫 가방 | 높은 유한 `fieldQuality` → 높은 첫 가방 구축률 → 높은 P → 많은 실제 스핀 → 적은 미노 | `첫 가방 기반 평가`, 원시 Q를 점수로 표시 |
| 두 기록 모두 두 가방 이상 | 높은 `S×P/max(7,m)` → 높은 P → 많은 가방 → 많은 실제 스핀 → 높은 원시 Q → 적은 미노 → 높은 유효 성공률 | `성공률 반영 효율`, `7S×P/max(7,m)` 스핀/가방 |

없는 값이나 유한하지 않은 기반 품질은 좋은 품질로 취급하지 않는다. 첫 가방에서는 같은 품질과 구축률 근거까지 동률일 때에만 실제 스핀 수를 비교한다. 이후의 공개 효율에는 첫 준비 가방의 미노 수도 포함한다. 실제 목표 완성은 별도로 가장 적은 허용 종료 미노 수, 그 비용에서의 성공률, 전체 유효 성공률 순으로 비교한다. Rust와 TypeScript는 같은 비교 순서를 사용하며, 누적 최대 스핀은 별도 진척 수치다.

### 실제 스핀 수에 따른 가방별 확률 허용

전체 성공률과 각 가방의 하한을 만족해야 인증 경계로 채택된다. 기본값은 전체 100%, 두 번째 가방부터 각 가방 100%, 독립적인 첫 가방 80%이며 첫 가방 확률 제외가 기본이다. 미노 제한 119와 탐색 상한 126을 구분한다. 첫 가방의 별도 하한을 0으로 설정해도 성공하는 시작 공급이 하나 이상 있어야 하며, 첫 가방 확률을 제외하더라도 그 구성 가능성과 전 공급의 일반 배치 안전성은 검사한다.

두 번째 가방부터는 `risk_min_spins_per_bag`가 100% 미만 구축을 허용할 최소 실제 Spin Single 수를 정한다. 기본값은 3, 허용 범위는 정수 0–6이고 0은 이 추가 조건을 끈다. 가방의 실제 증가량을 g, 설정값을 r, 사용자가 정한 가방별 하한을 f_b라고 하면:

```text
가방별 요구 하한 = 100%     (g < r)
가방별 요구 하한 = f_b      (g ≥ r)
```

기본 설정에서는 0·1·2스핀 가방이 5,040개 공급 모두 성공해야 하며, 3스핀 이상일 때에만 설정된 가방 하한까지 완화할 수 있다. 이 g는 같은 고정 계획의 `expected_spins−start_spins`이고, 실제 검증의 종료 스핀과 일치해야 한다. 후속 예측, 다른 경로의 마무리 미노, 준비용 일반 배치는 g에 더하지 않는다. 첫 가방에는 이 조건을 적용하지 않는다. 설정 화면의 `확률 완화 최소 스핀`에서 값을 바꿀 수 있으며, 저장된 명시적 0은 보존하고 필드가 없는 이전 설정에는 3을 채운다.

확률을 이미 사용했다면 남은 가방에 요구되는 누적 성공률도 높아진다. 인증 접두부의 확률이 P이면 나머지는 적어도 `전체하한/P`를 충족해야 하므로, 실제 다음 가방은 위 가방별 하한과 이 남은 요구량을 모두 만족해야 한다. 예를 들어 전체 50%·가방별 75%에서 75% 가방 두 개를 사용했다면 누적은 56.25%이고, 다음 가방은 최소 8/9(약 88.89%), 즉 5,040개 중 4,480개가 필요하다. 그 가방이 실제 스핀 수 제한에 못 미치면 이보다 강한 100%를 요구한다.

아직 최종 스핀 수가 정해지지 않은 제안 생성에는 낙관적인 공급 하한을 사용하지만, 고정 계획의 검증 상한으로 계속 통과할 수 있는지 판단할 때와 최종 채택 때에는 실제 증가량 조건을 적용한다. 정확한 종료 비용 CDF도 각 비용 시점에서 같은 가방별 하한과 누적 요구량을 만족해야 한다. 전체·가방별 성공률을 완화해도 일반 무클리어 배치의 안전성은 모든 5,040개 공급에 요구한다. 이 확률 판정은 휴리스틱 점수나 페이스 가산으로 대신하지 않는다.

가방별 구축률은 인증서에서 가져와 100%도 표시한다. 예측 자료 `forecastSpins`, `forecastSpinsByBag`, `forecastPlacements`는 보관한 두 가방 수순의 설명이며 실제 진행이 아니다. 같은 인증 계획을 새 예측만으로 자동 갱신하는 별도 경로는 이 구현에 포함하지 않는다. 인증된 최선 경로에서 대표 입력을 재생하고, 현재 탐색 중인 필드는 결과 상태만 표시한다.

내보내기의 `selectiveSearch.foundationPolicy`에는 첫 가방 순위, 배치별 지형 계수, 두 번째 가방부터의 스핀 비교, 목표 완성 우선권과 무클리어 두 접두부 검사의 범위를 기록한다. `continuationDiversity`에는 마무리 종류·위치의 분산 순서, 준비 한도 3, 수순 보관 한도 6, 공동 준비와 깊은 탐험의 범위를 기록한다. 별도의 `continuationAlternatives=6`은 대표를 포함한 보관 수다. `probabilityBudget`은 실제 스핀 제한값과 검증된 확률 소비 페이스를 설명하고, `displayPartialRanking`은 첫 가방과 이후 경로의 공개 비교 순서를 기록한다. 이 메타데이터는 점수와 선택 정책을 설명하며 입력이나 공급 인증을 대신하지 않는다.

- [TeaL의 두 번째 가방](https://harddrop.com/wiki/TeaL#Bag_2)은 넓은 아래 공동과 안쪽으로 이어지는 위쪽 벽을 살피는 형상 자료다. 미확정 마무리에 쓸 말림 가점과 구체적 목표의 준비 지붕 가점을 구분한다. 같은 문서가 중력 대기를 피하는 별도 경로도 다루므로, 도식만으로 Sonic 입력이나 전 공급 구축률을 인증하지 않는다.
- [Mechanical Hearts](https://harddrop.com/wiki/Mechanical_Hearts)와 [Interchangeable Shapes](https://harddrop.com/wiki/Interchangeable_Shapes#Chiptooth/Hearts)는 같은 점유 모양의 다른 미노 배정과 간접 받침을 검토하는 자료다. 같은 보드라는 이유만으로 배정·재고·선행 조건을 합치지 않는다.

이 자료들은 특징을 설계하는 근거이며 현재 계수가 최적이라는 증거가 아니다. 공개 도식의 수순을 시작 패턴으로 하드코딩하거나 Neyra의 P7 인증서로 사용하지 않는다. 목표 목록·프로브·beam은 유한하고, 정적인 접근성은 입력 도달성과 다르며, 배치 두 수순의 독립성은 가방 전체의 모든 공급을 뜻하지 않는다. 개선 채택과 고정 기준 소스와의 비교는 같은 조건의 실제 탐색 및 인증 자료로 별도 판단한다.
