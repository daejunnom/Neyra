# 다음 가방 CNN으로 넘어가기 위한 체크포인트

이 문서는 구현 계약과 다음 승인 기준이다. 실험 결과나 완주 성능 보고서가 아니다.
개발은 가장 최근에 채택한 소스에서 진행한다. 이전 소스를 별도 기준 엔진으로 유지하지 않는다.
공개 Pages의 평가기는 기존 구조 평가이며, 학습 자료 제공은 기본 off다.

## 이번 중간 단계의 구조

| 단계 | 계약 |
| --- | --- |
| 입력 | 실제 2가방 이후의 비어 있지 않은 보드. 추론 채널은 현재 점유만 사용한다. |
| 표지 | v5에서 사전 정제한 시작 필드의 다음 한 가방 실제 최선 관측. 전역 최적값·구축률이 아니다. |
| 실제 확인 | 한 시작점의 한 가방 안에서 지속 탐색한다. 실제 스핀 최대를 우선 보존하고 작업·중복·용량 중단을 기록한다. |
| 노드 선택 | 평가값의 비어 있지 않은 구간과 그 안의 노드를 차례로 무작위 선택한다. 낮은 점수 구간도 후보 풀에 보존한다. |
| 준비 경로 | 첫 가방 0스핀도 보존하고, 실제 일곱 미노 입력을 재생한 경계를 다음 가방으로 연장한다. |
| 전망 보완 | 실제 결과 필드는 나중의 독립적인 한 가방 관측으로 이어 갈 수 있다. 부모 경로와 각 관측을 보존하고 이득을 원래 표지에 합산하지 않는다. |
| 데이터 계보 | 원래 물리 방향과 부모 기록을 보존한다. 학습 점유의 동일·미러 중복은 같은 분할 성분에 묶는다. |
| 모델 | 기존 v2–v4 의미를 보존한다. v5도 같은 33,442개 매개변수와 한 가방 출력 두 개를 유지한다. 관측 스핀의 과소 예측 비용은 같은 크기의 과대 예측보다 두 배다. |
| 반복 학습 | 매번 전체를 다시 학습하지 않고 새 자료 최대 16개·과거 자료 최대 48개를 뽑는다. validation은 최대 64개의 안정된 표본으로 유지한다. |

## 다음 모델을 채택하기 전 필요한 확인

1. **한 가방 정밀도와 다양성.** 출발 depth를 올리는 것을 정밀 탐색으로 대신하지 않는다. 여러 출발 깊이를 무작위 평가 구간으로 선택하고, 같은 가방 안의 예산에 따른 최선 스핀 안정성·중복 절감·용량 중단을 확인한다. 전체 가방 도달률과 0스핀 비율을 기록한다. 같은 run/미러를 늘린 수를 독립 표본 수로 쓰지 않는다.
2. **안정적인 분할.** 새 그룹은 기존 학습 입력의 점유 성분을 먼저 따르고, 제약 없는 성분만 해시 배정한다. 결과 보존만으로 생긴 충돌은 해당 입력·후손에 국한한다. 과거 분할과 제외 이벤트를 변경하지 않으며, 잘못된 결과 전용 격리는 원인 감사와 원자적 재확인 뒤 복구 이력을 추가한다. 실제 학습 입력의 충돌은 계속 차단한다. 충분한 train/validation/test 성분이 모이지 않으면 임의 재분할해 학습을 강행하지 않는다.
3. **관측의 재현성.** 수집 소스·규칙·고정 예산 해시와 입력 재생이 맞아야 한다. 클라이언트 보고와 비공개 독립 측정을 구분하고 일부 표본을 재측정해 차이를 기록한다. 부재는 검열된 부재이며 불가능의 정답으로 해석하지 않는다.
4. **한 가방 헤드의 실제 학습.** 같은 v5 정책·작업 범위의 정제 자료로만 학습한다. 입력·한 가방 표지와 원본 재생 증거를 남긴다. 이전 특징을 쓸 때는 출력 헤드를 초기화하고 출처를 남긴다. 존재 예측은 Brier/보정, 개수는 MAE·평균 부족량·평균 초과량·과소 예측률과 출발 깊이별 편향을 확인한다. 과소 예측을 줄였다는 주장은 독립 validation에서 확인해야 한다. 표본 제거가 이전 가중치의 오염까지 취소하지 않으므로, 제외된 학습 계보는 적격 조상 또는 초기 모델로 되돌린다.
5. **짧은 전망의 부작용 확인.** 0스핀 준비 뒤 후속 가방에서 이득을 얻는 경로는 별도 평가 집합으로 확인한다. 한 가방 표지는 현재 관측 범위를 넘겨 합산하지 않으며, 장기적인 준비 가치가 입증됐다고 주장하지 않는다. 새로운 적응형 예산·장기 전망 정책은 별도 버전으로 측정한다.
6. **추론과 탐색의 비용.** 같은 필드·규칙·작업량에서 CPU 추론 비용과 끝까지 이어진 후보 품질을 함께 측정한다. 캐시 hit 수, 피한 실제 작업, 통신량, 벽시계 시간을 구분한다. 계산 공유는 ABBA로 확인하며 새 기준 소스의 품질을 떨어뜨리지 않는 변경을 채택한다.
7. **공개 모델 변경.** Rust/브라우저/선택적 ORT의 수치 일치, 모델·데이터 해시, 고정된 사용자 모델, 실패 시 CPU 동작을 확인한 뒤 별도 승인된 모델만 제공한다. 데이터가 새로 들어왔다고 모델을 자동 교체하지 않는다.

## 이후 40L 엔진에 필요한 별도 계약

점유 특징 추출부는 재사용할 수 있다. 그러나 같은 점유라도 이미 지운 줄 수와 남은 목표가 다르면 완주 비용은 다르므로, 최종 비용 헤드는 `40 − 완료 스핀`과 적용 규칙에 조건화해야 한다. 현재 점유만 받는 다음 가방 헤드에 그 값을 암묵적으로 섞지 않는다.

향후 제어기는 보드 예측으로 탐색 우선순위를 정하되 모든 노드에 최소 확인 예산을 남기고, 실제로 배치한 가방의 스핀 보상을 기록하며, 결과 경계에서 다시 평가하는 방식으로 확장할 수 있다. 실측된 짧은 경로와 잎의 예측값은 구분해 사용한다. 조상 피드백에는 이어진 실제 입력 경로와 유효한 표지 구간이 필요하다. 다른 가방의 보상을 원래 한 가방 표지에 더하지 않는다.

40L 완주 미노 수에는 실제 완주 자료 또는 명시적인 검열 목적함수가 필요하다. 미완성 탐색의 미노 수를 정답으로 삼지 않는다. 이 자료와 비교가 마련되기 전에는 사용자의 미노 제한을 제거하지 않는다. Transformer는 독립적인 경로 자료와 장기 문맥이 충분해졌을 때 별도로 비교하며, 한 가방 CNN의 수집·검증을 늦추는 선행 조건으로 삼지 않는다.
